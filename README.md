# Hotel Management System - DevOps Project

## Project Overview
A full-stack hotel management application deployed using Docker and AWS with CI/CD and monitoring.

## Tech Stack
- React Frontend
- Spring Boot Backend
- MariaDB
- Docker
- Docker Compose
- GitHub Actions
- AWS EC2
- Prometheus
- Grafana

## Features
- Hotel room management
- Booking system
- REST APIs
- Containerized deployment
- Automated CI/CD pipeline
- Monitoring dashboard

## DevOps Workflow
GitHub → GitHub Actions → AWS EC2 → Docker Compose → Monitoring Stack

## Monitoring
- Prometheus metrics collection
- Grafana dashboards
- Node Exporter monitoring

## Deployment
Application deployed on AWS EC2 using Docker Compose.
