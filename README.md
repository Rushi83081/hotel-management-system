# 🏨 Hotel Management System - DevOps Project

## 📌 Project Overview
A full-stack **Hotel Management System** designed and deployed using modern **DevOps practices**.  
The application is containerized using **Docker**, deployed on **AWS EC2**, automated with **CI/CD pipelines**, and monitored using **Prometheus & Grafana**.

# 🚀 CI/CD Pipeline

The project uses **GitHub Actions** for Continuous Integration and Continuous Deployment.

## 🔧 CI/CD Process
1. 👨‍💻 Developer pushes code to GitHub
2. ⚡ GitHub Actions pipeline starts automatically
3. 🐳 Docker images are built
4. ☁️ Application is deployed to AWS EC2
5. 📦 Containers are managed using Docker Compose
6. 📊 Monitoring tools collect application and server metrics
